# Prince Store — Task 5 Capstone

A responsive e-commerce product catalog built using HTML5, CSS3 and vanilla JavaScript.

## Features

- Modular frontend structure
- Hash-based client-side routing
- Product data from DummyJSON REST API
- `fetch()` with `async/await`
- Network error handling
- Search, category filtering and sorting
- Product detail pages
- Shopping cart CRUD operations
- `localStorage` persistence
- Responsive design for desktop, tablet and mobile
- Lazy-loaded product images
- Accessible labels and semantic HTML

## Run locally

1. Open the folder in VS Code.
2. Use the Live Server extension, or open `index.html` in a browser.
3. Make sure the browser has internet access because products are loaded from:
   `https://dummyjson.com/products`
